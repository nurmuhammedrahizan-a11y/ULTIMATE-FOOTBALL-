# Ultimate Football

A small, responsive arcade football game that runs directly in a modern browser. No build tools or dependencies are required.

## Play

Open `index.html` in a browser, or publish the repository with GitHub Pages.

- **WASD / arrow keys** — move your player
- **Space** — shoot or pass when near the ball
- **Shift** — sprint
- **P** — pause / resume
- **Enter** — start or restart
- **Touch screens** — drag on the left side of the pitch to move; tap the right side to shoot

Matches last two minutes. Score more goals than the red team to win. Sound effects are synthesized in the browser and can be muted with the music-note button.

## Project files

- `index.html` — accessible game shell and match UI
- `style.css` — responsive visual design
- `game.js` — canvas rendering, controls, match logic, and simple team AI

## Notes

The game is a lightweight arcade prototype, not a licensed simulation. Team names, artwork, and player behavior can be extended as the project grows.
